精力怎么分

你给的 20 / 50 / 30。姐姐唯一想提醒的是：B 和 C 在数据层是共享的，别重复劳动。

A · ESG 评级分歧GW_rd20%
多家机构给的 ESG 分差得越远，越可能在洗绿。文献最成熟、见效最快——先做它，用来建立信心。短板是免费数据下样本只有几百家。
B · 披露—表现缺口GW_gap50%
对外披露写得很漂亮，实际环保表现很一般，这个缺口就是洗绿。逻辑最直观、面试官最容易听懂——它是你论文的主心骨。难点在「实际表现」要靠多个弱指标合成。
C · 文本 / 大模型法GW_text30%
年报里绿色话术很多，真金白银投入很少，用 NLP 抓出这个落差。最原创、FinTech 含量最高——它是让你和别人拉开差距的东西。🔑 关键：B 的「表现侧」数据要靠 C 的年报解析，两条线共用一个数据底座。

2026 · 9月奠基：把「想做」变成「在做」立项 · 文献 · 工具跑通公共
要做什么
  • 今天就建 GitHub 仓库，写 README 讲清研究问题——commit 历史从第一天算起，这是你最强的可信证据
  • 精读 8–10 篇核心文献，做成文献矩阵（作者 / 数据 / 方法 / 结论 / 你和它的差异）
  • 必读三篇：Berg, Kölbel & Rigobon (2022) Aggregate Confusion、Gibson Brandon, Krueger & Schmidt (2021) FAJ、陈宏韬等 (2025)《财经研究》ESG 评级分歧与股价同步性
  • 注册 Tushare，拉通一只你熟悉的股票：日线 + 三大报表
  • 去中证指数官网手动查 10 家公司 ESG 评级，亲手感受数据长什么样、口径是否统一
  • 开始写研究日志，每周至少一条（模板在 RESEARCH_LOG/）

GitHub 仓库 + 文献矩阵 + 研究日志第 1 篇
验收标准
你能用三句话讲清「我的研究和已有文献的差异在哪」

2026 · 11月A 路径：ESG 评级分歧最快拿到第一个属于自己的变量20%
要做什么
  • 中证 / 华证 / MSCI 评分标准化：先转「行业 × 年份」百分位，再取标准差（口径不同，不标准化就没意义）
  • 描述性统计：分歧到底有多大？哪些行业分歧最大？
  • 本土 vs 海外：中证/华证 与 MSCI 的系统性差异（这是文献里的重要维度）
  • 预案：若 MSCI 覆盖不足 200 家，改用中证 + 华证做本土分歧，MSCI 只留作子样本对比

验收标准

2026 · 12月 – 2027 · 2月C 路径：文本与大模型你最原创的那部分30%
要做什么
  • 全量报告解析：pdfplumber 提取正文，扫描件上 OCR
  • 抽取「环境 / 可持续」章节，切片成段落
  • 自建绿色词库：参考《绿色产业指导目录(2019)》，再手工补充漂绿话术特征（模糊承诺、缺时间表、无量化目标）
  • TF-IDF / 词频强度 → 披露强度
  • 调大模型 API：让模型对「承诺—行动匹配度」打分 0–5
  • 人工抽检 50 份验证一致性，报告相关系数或 Kappa
  • 省钱技巧：只送关键段落、不送全文，API 成本能降约 90%
交付物
GW_text 变量 + 一致性检验报告
验收标准

2026 · 12月 – 2027 · 3月B 路径：披露—表现缺口主力指标，论文的主心骨50%
要做什么
  • 披露侧：中证 ESG 评分（或自建披露质量评分）
  • 表现侧（多指标交叉，建议用主成分合成）：
    · IPE 环保处罚次数与金额
    · 排污许可平台的实际排放量
    · 绿色专利数量（国家知识产权局）
    · 年报披露的环保投入 / 能耗
  • 标准化后取差：GW_gap = z(披露) − z(表现)
  • 分行业描述统计：重污染行业的缺口是不是更大？
  • 🔑 关键提醒：表现侧数据高度依赖 C 的年报解析成果，两条线共享数据底座，别重复劳动

验收标准

2027 · 2月 – 3月补计量 + 事件研究做那个最干净的检验实证

风险与预案

每一条都是这个项目真实会遇到的坑。提前想好，遇到了才不慌。

风险概率预案
年报 PDF 大量是扫描件高10 月就抽样统计比例。若超过 30%，改用 OCR 服务，或把样本收缩到文本版报告——收缩要有依据，并在论文里写明
「实际环保表现」披露不规范高不指望单一指标。用处罚 / 排污 / 绿色专利 / 能耗四个弱指标做主成分合成，缺一两个不致命
MSCI 覆盖样本太小中改用「中证 + 华证」做本土分歧，MSCI 留作国际对比子样本，反而是个加分的分析维度
大模型 API 成本超预算中只送关键段落不送全文（省约 90%）；先跑 200 家看效果，再决定要不要扩到全样本
回归不显著中不显著也是结论。诚实报告，然后做机制分析解释「为什么市场没反应」——比如投资者根本没看、或披露信息质量太低。这比硬凑一个显著结果有价值得多
被 A-Level 挤压、进度掉队高每个阶段都有 MVP。宁可交一个缩水但跑通的版本，也不要让整条线断掉——断了就很难接回来
