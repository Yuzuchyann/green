## 一、本周做了什么（按逻辑顺序，非时间顺序）

### 1. 关键决策：数据源统一为 AkShare

- 行情、估值（市值/PE/PB）、财务**全部走 AkShare**，不再 Tushare + AkShare 混用。
- 理由：混用会带来字段名、交易日历、复权方式三处不一致，下游清洗必然出岔子；且 Tushare 免费层仅 `daily` 可用，其余接口 2000 积分（变相付费），违背「只靠免费数据」的硬约束。Tushare 降级为**可选交叉验证备份**（需注册攒 120 分）。

### 2. 工程产出

- 新建 `src/fetch_akshare.py`：复用原 7 表 SQLite schema 与 `sync_log` 断点续传逻辑，AkShare 数据写入同一批表，**下游清洗代码零改动**。
- 更新 `requirements.txt`：AkShare 为主源，Tushare 降级为可选交叉验证（注释标明其积分墙）。
- 提交 `b850c8b`「Add unified AkShare fetcher; demote Tushare to optional cross-check」，已推送 Gitee + GitHub（`ls-remote` 验证两边 HEAD 均为该提交）。

### 3. 验证路径：3 只 → 50 只 → 全市场分批

| 阶段 | 目的 | 结果 |
| - | - | - |
| 3 只测试股（2024 全年） | 验证端到端流程 + 抽样核对数据质量 | 跑通；平安银行 total_mv≈1787 亿、pb≈0.45，量级合理 |
| 50 只试点（全窗口 2018–2026） | 验证批量稳定性 | **暴露并修复一个关键缺陷**（见第三节），最终 50/50 全覆盖 |
| 全市场第一批（第 51–1050 只） | 正式量产 | 行情推至 1014/1050（96.6%），财务未启动 |

## 三、遇到的问题与解决（按问题归类）

### 1. 数据源本身的坑（AkShare 免费接口的边界）

| 问题 | 处理 | 状态 |
| - | - | - |
| 资产负债表接口 `stock_balance_sheet_by_yearly_em` 报 `NoneType not subscriptable` | try/except 跳过；Size 用 `total_mv` 代理，BM 暂缺 | ⚠️ 长期局限 |
| 免费接口不返回财报实际公告日（ann_date） | 财务按报告期对齐 | ⚠️ 前视偏差，论文披露 |
| 东方财富日线源连接被中止 | 改用新浪源 `stock_zh_a_daily` | ✅ 已解决 |
| akshare 1.18.x 移除 `stock_a_indicator_lg` | 改用 `stock_zh_valuation_baidu` 逐指标拉取再合并 | ✅ 已解决 |

### 2. 最有价值的发现：失败被「假完成」的缺陷

- **现象**：50 只试点中行情 18 只、财务 9 只请求失败（沙箱代理间歇性 502，失败呈「成片」特征），但这些失败任务仍被 `mark_done(task, 0)` 标记完成。
- **危害**：重跑时 `is_done` 会跳过它们 → **任何失败的股票都会静默永久缺失**。若没在 50 只试点阶段发现，全市场 5553 只里会埋下几百个看不见的洞。
- **修复**：① 失败分支去掉 `mark_done`，失败不再标完成 → 续跑自动重试；② DELETE 掉 27 只假记录（sync_log 101 → 74）；③ 重跑补齐，daily 65,964 → 103,634 行、fina 5,052 → 5,759 行，pilot 达到 **50/50 全覆盖**。
- **教训**：断点续传 + 失败重试必须配合「失败不写 done」才成立，三者缺一不可。

### 3. 环境问题

- 裸解释器没装 pandas/akshare，首跑 `ModuleNotFoundError` → 统一用 venv 的 python（`envs/default/Scripts/python.exe`）。
- **版本债（未解决）**：venv 里 pandas = 3.0.5，违反 `requirements.txt` 的 `pandas<3.0`。当前能跑通，但偏离约定，全量收尾前需统一（降级 2.x 验证，或改 requirements 接受 3.x）。

## 四、已知局限（论文必须披露的三条）

1. **资产负债表缺失**：Size 变量用 `total_mv`（总市值）代理，BM 暂缺。
2. **前视偏差**：AkShare 不给财报公告日，财务指标按报告期对齐，存在轻微前视偏差。
3. **样本自选择**：核心样本仅为已披露可持续报告的公司（设计如此，写入论文的诚实局限）。

## 五、这周学到的

- 「不混用数据源」不是洁癖，是**审计可验证性**的硬要求：字段名、交易日历、复权方式任一不一致，下游全出问题。
- 免费数据的真实边界：Tushare 免费额度远比想象窄，AkShare 才是真正零门槛的主源。
- 验证不能只看「跑通没报错」，还要**抽样核对量级**（如平安银行 total_mv≈1787 亿是否合理）。
- 小范围试点（50 只）的价值在本周被证明：假完成缺陷、网络 502 成片失败，都是试点先暴露的。
